已新增 code cell。它先記錄時間並截圖，再反覆掃描棋盤；每顆寶石依序嘗試右、上、下，成功時拖曳寶石並更新截圖，超過一分鐘就停止。
```python
import time

start_time = time.time()
im = pyg.screenshot()

while time.time() - start_time < 60:
    for r in range(8):
        if time.time() - start_time >= 60:
            break
        for c in range(8):
            if time.time() - start_time >= 60:
                break
            if can_move_right(r, c, im):
                next_r, next_c = r, c + 1
            elif can_move_up(r, c, im):
                next_r, next_c = r - 1, c
            elif can_move_down(r, c, im):
                next_r, next_c = r + 1, c
            else:
                continue
            x, y = gem_position(r, c)
            next_x, next_y = gem_position(next_r, next_c)
            pyg.moveTo(x, y)
            pyg.dragTo(next_x, next_y, duration=0.2, button='left')
            pyg.sleep(0.1)
            im = pyg.screenshot()
```
